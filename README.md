## 🌟 Öne Çıkan Özellikler ve İnovasyon Modülleri

### 🧠 1. Microsoft ML.NET Yapay Zeka & Makine Öğrenmesi
- **FastTree Karar Ağacı Sınıflandırması:** Rezervasyon iptal risklerini (Lead Time, Kanal, Süre vb.) %88+ doğrulukla tahmin eder.
- **Canlı Simülasyon & "What-If" Laboratuvarı:** Kaydırıcılar (sliders) ile rezervasyon parametrelerini değiştirerek milisaniye seviyesinde anlık risk skorlaması.
- **Açıklanabilir Yapay Zeka (XAI - Feature Attribution):** Model kararlarının arkasındaki faktörlerin yüzdesel dağılımı.
- **Her Yerden Erişilebilir AI Copilot (Sesli Destek):** Web Speech API ile Türkçe konuşma tanıma (STT) ve sesli yanıt (TTS).

### 🏢 2. Endüstri 4.0 IoT 3D Dijital İkiz (Three.js)
- **4 Kat, 40 Oda ve Çatı Havuzu:** Otelin mimari yapısını tarayıcıda 3 boyutlu interaktif olarak modeller.
- **Canlı IoT Sensörleri:** Her oda için gerçek zamanlı sıcaklık, nem ve enerji tüketimi telemetrisi.
- **Uzaktan Akıllı Kapı Kontrolü:** 3D model üzerinden tek tıkla oda kapısını uzaktan açma/kilitleme.

### 📸 3. Biyometrik Yüz Tanıma & EGM KBS Kiosku
- **128 Boyutlu Vektör Karşılaştırması:** %98.9 benzerlik oranıyla temassız hızlı check-in.
- **EGM Kimlik Bildirim Sistemi (KBS):** Emniyet Genel Müdürlüğü mevzuatına uygun anlık misafir bildirim entegrasyonu simülasyonu.
- **Sesli Karşılama:** Misafiri adı ve soyadıyla karşılayan akıllı kiosk deneyimi.

### 📈 4. Uçuş & Dinamik Gelir Radarı (Yield & ADS-B)
- **Havalimanı Canlı İniş Telemetrisi:** Bölgeye iniş yapan uçuşlar, yolcu yoğunluğu ve gecikmeler.
- **Bölgesel Etkinlik & Hava Durumu:** Stadyum konserleri ve hava durumu korelasyonuyla dinamik fiyat çarpanı hesaplama.
- **Otomatik Fiyat Optimizasyonu:** Talep yoğunluğuna göre oda fiyatlarını otomatik revize etme.

### 🕵️‍♂️ 5. Rakip Otel Fiyat Casusu (Rate Shopper)
- **Canlı Pazar Taraması:** Çevredeki 5 yıldızlı tesislerin fiyatlarını anlık analiz eder.
- **MPI (Market Penetration Index):** Pazar penetrasyonu ve rekabet endeksi hesaplama.
- **Kanal Entegrasyonu:** Booking.com, Expedia, Airbnb fiyatlarını tek tıkla güncelleme.

### 🗺️ 6. AI Kişisel Tur Rehberi & Akıllı Gezi Rotası (Trip Planner)
- **Misafir İlgi Alanı Analizi:** Tarih, deniz, gastronomi veya doğa odaklı kişiselleştirilmiş rota önerileri.
- **Adım Adım Gezi Planı:** Yürüme mesafeleri, süreler ve yerel rehber tavsiyeleri.

### 📱 7. Misafir Dijital Mobil Anahtar (NFC Simülatörü)
- **Temassız Kapı Açma:** Akıllı telefondan nabız atan NFC animasyonu ile kapı kilidini açma.
- **Oda Servisi & Folyoya Yazma:** Misafirin telefondan verdiği siparişi doğrudan oda folyosuna borç kaydetme.
- **Tek Tıkla Wi-Fi Bağlantısı:** Şifresiz, tek tıkla misafir ağına bağlanma.

### ☀️🌙 8. Çift Tema & İki Dilli Arayüz
- **Dinamik Açık (Light) & Koyu (Dark) Tema:** Sıfır titreme (FOUC önleyici) ve `localStorage` kalıcılığı ile anlık tema geçişi.
- **Türkçe & İngilizce (TR/EN) Yerelleştirme:** Tam kapsamlı çift dilli altyapı.

## 🚀 Hızlı Başlangıç

### Gereksinimler
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)
- [Microsoft SQL Server Express](https://www.microsoft.com/sql-server/sql-server-downloads) (veya LocalDB)
- Modern bir web tarayıcısı (Chrome, Edge, Firefox vb.)

### 1. Depoyu Klonlayın
```bash
git clone https://github.com/hasanderyalar0/otelpro.git
cd otelpro
```

### 2. Veritabanını Hazırlayın
SQL Server Management Studio (SSMS) veya SQLCMD ile `database/02_objects.sql` betiğini çalıştırın veya `appsettings.json` dosyasındaki bağlantı dizesini kontrol edin:
```json
"ConnectionStrings": {
  "Default": "Server=localhost\\SQLEXPRESS;Database=OtelDb;Trusted_Connection=True;TrustServerCertificate=True;MultipleActiveResultSets=True"
}
```

### 3. Uygulamayı Başlatın
```bash
dotnet restore
dotnet run --project src/Otel.Web/Otel.Web.csproj
```

Uygulama varsayılan olarak **`http://localhost:5102`** adresinde açılacaktır.
